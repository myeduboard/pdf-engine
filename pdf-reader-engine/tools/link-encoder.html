Link encoder

Turns a document URL into a token so the address is not sitting in your page source, then writes the embed block for you. Everything runs in this page — nothing is uploaded.

A PDF, an HTML notes file, or a JSON contents file. Must be reachable over HTTPS and send CORS headers — jsDelivr, GitHub raw, Cloudflare R2 and S3 all do.

Same value must go in key on the page.


    
    

    
  


  

    A token keeps the address out of your page source and out of casual view. It does not make the file secret — anyone who opens the browser's network panel while the page loads can still see where the bytes came from. If the file genuinely must stay private, put a proxy in front of it (see proxy/ in this repo) so the browser only ever sees your proxy address.
